KOMARO 製品の全体図

作成：辻直哉（個人開発・KOMARO）。最終更新は2026年11月11日です。配信と審査の状態は、この日に確かめました。

みんなの空いている時間を集めて、日程を決めるサービスです。表のマス（コマ）を押すだけで答えられます。登録は要りません。ブラウザと iPhone アプリで使えます。この資料には、仕組み、使う流れ、端末ごとの違い、お金のしくみ、広告の状態をまとめています。

印の意味：配信中 は今使えるもの、審査中 は申し込み済みで結果待ちのもの、予定なし は当面やらないものです。

02

全体の仕組み

画面もデータの出し入れも、Vercel に置いた1つのプログラムがまとめて受け持ちます。iPhone アプリは別物を作っているのではなく、同じ komaro.app を表示する器です。そのため Web を直せば、アプリも次に開いた時点で新しくなります。

部品使っているもの役目
画面と APINext.js 16（React 19）表示とデータの出し入れを1つのプログラムで受け持ちます。
置き場所Vercelmain に push すると本番が入れ替わります。
データPostgreSQL（Neon）、Prismaイベント、参加者、コマの○×、コメントを保存します。
iPhone アプリCapacitorkomaro.app を表示する器です。通信できないときはアプリに同梱した案内を出します。
AIGemini話した言葉と、予定表の画像から日程を読み取ります。

05

できること

表の形

作るときに3つから選びます。あとから形は変えられません。

形表の中身向いている場面
カレンダー形式日付または曜日 × 時間帯打ち合わせ、飲み会など、時刻で決めるもの
時間割形式日付または曜日 × 時限大学の授業や部活など、時限で動くもの
日付形式日付のみ日帰りや宿泊など、日だけ決めるもの

主な機能

機能状態内容
コマで答える配信中押す、またはなぞって、まとめて選べます。
回答の修正と削除配信中参加者一覧の名前を長押しします。
コメント配信中集計ページに一言を残せます。
カレンダーに追加配信中Google、Yahoo、Outlook、TimeTree、Apple に送れます。
音声入力配信中話した言葉から候補日を作ります。
画像から読み取る配信中予定表の写真から候補日を作ります。
編集用パスワード配信中任意です。設定すると、編集用 URL を知っていてもパスワードが要ります。
参加者の上限配信中初めは50人です。主催者が変えられます。
ホーム画面に追加配信中Android とパソコンでは、アプリのように追加できます。

消したあとの扱い

イベントを消すと、まず「削除済み」の印が付きます。30日たってから、中身を完全に消します。誤って消したときに戻せるようにするためです。

07

お金のしくみ

利用者からはお金を取りません。有料プランも、回数の上限もありません。収入は広告だけです。

広告の置き方には決まりがあります。操作の途中と、送信ボタンのすぐ近くには置きません。押し間違いは広告主への無効なクリックとして数えられ、広告の口座が止まる直接の原因になるためです。回答中の画面と、利用規約・プライバシーポリシーには広告を出しません。

場所置くもの決まり
ブラウザAdSense の枠用意した9か所のうち5か所を有効にしています。1つの画面に1つまでです。
iPhone アプリAdMob のバナーと全画面回答・修正の画面と、規約のページには出しません。
広告が出ないときアプリへの案内広告ではないので、広告の決まりは関わりません。広告が配信され始めると、自動で出なくなります。

数字（訪問者、利用者、ダウンロード、広告の収益）は管理画面にまとめています。ads.naoya-tsuji.com

09

気をつけること

編集用 URL をなくすと戻せません

イベントを直す・消すには編集用 URL が要ります。作成完了の画面でしか出ないため、なくすと作った本人でも操作できなくなります。

表の形は、あとから変えられません

カレンダー形式で作ったものを時間割形式にはできません。候補の日時は増やせます。

広告の収入はまだわずかです

ブラウザの広告が審査中で、収入は iPhone アプリの分だけです。ブラウザが通れば増える余地があります。

Android アプリはありません 予定なし

Android とパソコンでは、ブラウザから「ホーム画面に追加」すればアプリのように使えます。
